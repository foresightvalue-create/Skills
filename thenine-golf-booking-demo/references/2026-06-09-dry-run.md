# 2026-06-09 더나인GC 예약 시연 드라이런 기록

## 목적

더나인GC 골프예약 시연을 처음부터 다시 실행해 보며, 실제 속도 병목과 시연상 위험 지점을 확인했다. 실제 예약/결제/최종 제출은 진행하지 않았다.

## 확인된 경로

### Naver 검색 경로

- 검색어: `더나인 골프클럽`
- Naver 장소 카드가 바로 노출됨.
- 장소 카드 정보:
  - 주소: 전북 김제시 금구면 대화1길 8-75
  - 전화번호: 063-548-3650
  - 홈페이지: `http://theninegc.co.kr/`
- Naver 장소 카드 안에도 예약 영역이 표시될 수 있음.
- 단, 노출 티타임에 `4인 필수`, `9홀X2회`, 제공자 `티스캐너` 조건이 보일 수 있으므로 3명 기본 시나리오와 불일치하면 그대로 예약 진행하지 말 것.

### 공식 사이트 경로

- 공식 URL: `https://theninegc.co.kr/`
- 상단 `BOOKING` 클릭 시 로그인 페이지로 리다이렉트됨.
- 로그인 URL 형태: `https://theninegc.co.kr/html/member/login.asp?gopath=/html/booking/booking01.asp`
- 로그인 페이지 입력 요소:
  - 숨은 이동 경로: `/html/booking/booking01.asp`
  - 아이디 입력: `loginId`, name `memb_inet_no`
  - 비밀번호 입력: `loginPw`, name `memb_inet_pass`
  - 아이디 저장 체크박스: `idSave`
  - 로그인 버튼

## 팝업 점검

2026-06-09 기준 공식 사이트 첫 진입 시 5개 팝업이 나타남.

- 제2퍼팅연습장 이용 안내
- 6월 이용요금
- 야간라이트 LED 교체 완료
- 야간무인자판기 오픈
- 카트비면제 / 6월 주중 이벤트

각 팝업 하단에는 `오늘 하루 동안 보이지 않기`와 `× CLOSE`가 있음.

주의:
- 팝업 이미지/본문은 공지 상세 링크다.
- 오클릭하면 공지사항 상세 페이지로 이동한다.
- 빠른 시연 중에도 반드시 하단 오른쪽 `× CLOSE` 또는 하단 왼쪽 `오늘 하루 동안 보이지 않기`만 클릭한다.

## 속도 결론

- 공식 사이트 직접 진입 후 로그인 페이지까지 네트워크 로딩은 약 1초 내외로 빠름.
- 체감상 느려지는 지점은 사이트 로딩이 아니라 5개 팝업을 하나씩 정리하는 장면.
- 강의 시간이 짧으면 시연 전 `오늘 하루 동안 보이지 않기`로 팝업을 숨겨두는 것이 가장 좋음.
- 팝업 정리를 보여줘야 하면 “공지 팝업을 빠르게 정리하겠습니다” 한 문장만 말하고 `× CLOSE`를 연속 클릭한다.

## 권장 시연 모드

### 전체 시연형

Naver 검색 → 장소 카드 확인 → 공식 홈페이지 → 팝업 정리 → BOOKING → 로그인 단계.

사용할 때:
- 브라우저 검색 능력까지 보여주고 싶을 때.

### 실전 속도형

공식 URL 직접 진입 → 팝업 정리/사전 숨김 → BOOKING → 로그인 단계.

사용할 때:
- 강의 시간이 짧고 예약 자동화 흐름 자체가 핵심일 때.
