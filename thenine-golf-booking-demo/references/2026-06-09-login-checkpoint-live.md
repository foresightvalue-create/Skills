# 2026-06-09 더나인GC 공식 사이트 BOOKING 로그인 체크포인트 재확인

## Context

대표님과의 더나인GC 예약 데모 세션에서 공식 사이트 직접 진입 → 공지 팝업 정리 → BOOKING 클릭까지 실제 브라우저로 재확인했다.

## Observed flow

1. `https://theninegc.co.kr/` 공식 사이트 접속.
2. 초기 공지 팝업 5개가 떠서 예약 메뉴 진입 전 모두 닫아야 했다.
3. 이번 실행에서 보인 팝업 제목:
   - 제2퍼팅연습장 이용 안내
   - 6월 이용요금
   - 그린통기
   - 야간무인자판기오픈
   - 카트비면제
4. 상단 `BOOKING` 메뉴 클릭 시 회원 로그인 페이지로 이동했다.
5. 로그인 페이지에 다음 요소가 보였다.
   - 아이디 입력칸
   - 비밀번호 입력칸
   - 아이디 저장 체크박스
   - 로그인 버튼
   - 회원가입
   - 아이디/비밀번호 찾기
   - 홈 바로가기

## Durable lesson

- 팝업 제목은 시즌/운영 공지에 따라 바뀐다. 스킬 본문에는 “5개 팝업이 나타날 수 있다”와 대표적인 제목을 적되, 특정 제목 목록을 고정된 사실처럼 다루지 않는다.
- `BOOKING` 이후 바로 티타임 목록이 아니라 로그인 페이지로 갈 수 있으므로, 로그인 전 상태는 “예약 불가”가 아니라 “로그인 후 티타임/예약 가능 여부 확인 필요”로 보고한다.
- 로그인 페이지 도달 후에는 예약을 진행한 것처럼 표현하지 말고 “예약은 아직 하지 않았고 로그인 단계까지 도달했다”고 짧게 상태를 먼저 말한다.
