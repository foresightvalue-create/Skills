# 더나인GC Visible Chrome 시연 실패/교훈 — 2026-06-09

## 상황

대표님은 더나인GC 예약 시연을 “브라우저가 실제 모니터에서 열리고 움직이는 모습”으로 보고 싶어 하셨다. 내부 브라우저로는 BOOKING → 로그인 단계까지 도달했지만 대표님 화면에는 보이지 않았다. 이후 로컬 Chrome을 열었으나 듀얼 모니터 환경에서 Naver 검색창/Chrome 창이 확장 모니터와 주 화면 사이에 섞여, 대표님이 마크의 조작 과정을 볼 수 없었다.

## 핵심 교훈

- 더나인GC 시연의 성공 조건은 텍스트 결과가 아니라 대표님/관객이 실제 Chrome에서 검색·클릭·이동을 보는 것이다.
- 내부 브라우저 성공은 visible demo 성공이 아니다.
- 듀얼 모니터에서는 Chrome이 어느 모니터에 있는지 먼저 확인하고, watched monitor로 옮긴 뒤 시작한다.
- `chrome.exe` 프로세스 존재, 창 제목 존재, 내부 스냅샷은 충분한 검증이 아니다. 현재 보이는 모니터 캡처로 확인해야 한다.
- 대표님이 “안 보여”, “애쓰는 모습을 못 보겠어”, “stop”, “그만”이라고 하면 즉시 조작을 멈추고 re-anchor한다.

## 다음 시연 절차 보강

1. 시작 전: “대표님, 어느 모니터에 Chrome을 띄울까요?” 또는 현재 watched monitor를 확인한다.
2. Chrome 창을 watched monitor 중앙/최대화 상태로 배치한다.
3. 현재 화면 캡처로 Chrome/검색창/주소창이 보이는지 확인한다.
4. 한 동작씩 보이게 진행한다: 검색창 선택 → `더나인 골프클럽` 입력 → 공식 사이트 클릭 → 팝업 닫기 → BOOKING 클릭.
5. 로그인 단계에서는 멈추고, 대표님이 직접 로그인하게 하거나 1회성 입력 승인을 받는다.
6. 예약 확정/결제/제출 전에는 기존 Final Confirmation Protocol을 따른다.

## 짧은 시연 멘트

“먼저 Chrome 창이 대표님이 보시는 화면에 있는지 확인하겠습니다. 이제 검색창을 선택하고 더나인 골프클럽을 검색합니다. 공식 홈페이지로 들어가고, 공지 팝업을 정리한 뒤 BOOKING 메뉴까지 이동하겠습니다. 로그인 또는 예약 확정 단계에서는 멈추겠습니다.”
